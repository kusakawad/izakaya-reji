# 居酒屋レジ

即売レジ風の操作にテーブル管理・税率切り替え・CSV出力・バックアップを足した、ブラウザで動く居酒屋向けレジです。
サーバー不要。データは使っている端末のブラウザ内に保存されます。

## 公開（GitHub Pages）
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存。
数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

## iPhoneでアプリとして使う
1. Safariで上のURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 以降はホーム画面のアイコンから起動（一度開けばオフラインでも動きます）

## 更新するとき
`index.html` を差し替えたら `sw.js` の `VERSION` を1つ上げてください（古い版がキャッシュに残るのを防ぎます）。
